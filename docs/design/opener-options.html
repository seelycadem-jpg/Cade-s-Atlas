The briefing opener in five colours

Every option uses the title face, Garamond, a size up, so the opener reads as a voice of its own. Only the colour changes. Each sits under the page title, the italic line and the tabs, above the body text with a link in it, in light and dark.

My pick: deeper espresso. If you want a new colour, navy.

With the Garamond doing the work, the espresso now shows as brown and keeps the page to the palette we have: paper, ink, espresso, red, gilt. Navy is the best new colour: it is quiet, it sits well with red, and it reads as ink on a chart. If it wins, it should mean one thing only: the opener, and nothing else on the page. Teal is calm but drifts toward the map. Aubergine and umber both pull toward the red and start to look like a second accent.
